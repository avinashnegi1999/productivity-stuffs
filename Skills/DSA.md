# DSA

Data structures and algorithms in Python. From basics to interview-ready.

| Track | Length | Time | For |
|:--|:--|:--|:--|
| [Standard](#standard-track) | 16–20 weeks | 1–2 hours a day | Interview-ready, fast |
| [Deep](#deep-track) | 28 weeks | 15 hours a week | Proofs, from-scratch builds, top-company level |

**Method:** Learn the concept. Build it in Python. Solve real problems. Check the complexity.

## Deep track

Weeks 13–40, after the [Python mastery track](Python.md#mastery-track). Build from scratch. Check complexity. Prove it correct. Test. Optimize. No other big course at the same time.

| Weeks | Learn and build | Gate |
|:--|:--|:--|
| 13 | Big-O, Θ, Ω, Master theorem · induction, loop invariants, exchange arguments | Write the invariant for insertion sort |
| 14–16 | Two pointers, sliding window, prefix and suffix arrays · build Rabin–Karp, KMP · 60–70 problems | Prove KMP correct |
| 17–18 | Monotonic stacks and queues, heap variants · build a binary heap, `MedianFinder` | Amortized proof: queue from two stacks |
| 19 | In-place reversal, Floyd cycle detection · build a persistent linked list | Explain structural sharing |
| 20–21 | Mergesort, quicksort, randomized select · binary search on value and on answer | Prove binary search correct |
| 22–23 | Traversals, LCA, AVL and red-black trees | Prove the AVL height bound |
| 24 | Trie, compressed trie, suffix array and LCP | Explain suffix array sorting and LCP |
| 25–27 | BFS, DFS, topological sort, SCC · Dijkstra, 0-1 BFS, Bellman–Ford · Kruskal with DSU, Prim with a heap | Prove Dijkstra correct |
| 28 | Interval scheduling, Huffman coding | Exchange argument proof |
| 29–31 | 1D and 2D DP, LIS, edit distance, bitmask DP · divide and conquer, monotone queue DP | Derive a DP and prove it acyclic |
| 32 | Union-find · segment tree with lazy propagation · Fenwick tree | Prove lazy propagation correct |
| 33 | Binary lifting, Euler tour, bridges, articulation points | Explain the DFS lowlink invariant |
| 34 | Aho–Corasick, polynomial hashing, sieve, combinatorics | Explain hash collision handling |
| 35 | Rebuild DSU, heap, segment tree, trie and LRU from memory | 60%+ on hard problems |
| 36–38 | Daily: 1 easy, 2–3 medium, 1 hard · 4 mocks: algorithms, debugging, DS design | 80%+ pass rate |
| 39–40 | Capstone. Pick one: typed DS and algorithms library, pathfinding visualizer, indexing engine | Shipped |

## Habits

- Consistency beats intensity. 1 hour daily beats 7 hours once a week.
- Review each topic on day 2, 4, 11 and 25.
- Code it from scratch first. Draw it. Explain it out loud. Keep a pattern cheat sheet.
- For every solution, check time, space, trade-offs and edge cases.
- Understand patterns, don't memorize answers. Plan before you code. Break hard problems into parts.
- Track a daily LeetCode streak, weekly weak spots, monthly mock scores. Update your resume every quarter.
- Reward yourself: daily goal, 30 minutes of fun. Weekly, a weekend treat. Monthly, a gadget or book. Interview-ready, a celebration dinner.
- Join [r/cscareerquestions](https://www.reddit.com/r/cscareerquestions/), [LeetCode contests](https://leetcode.com/contest/), [Dev.to](https://dev.to/) and [Discord coding servers](https://discord.gg/code).
