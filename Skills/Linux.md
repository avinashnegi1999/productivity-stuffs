# Linux

Try a distro first: [Ubuntu](https://ubuntu.com), [Linux Mint](https://linuxmint.com) or [Fedora](https://getfedora.org).

## Tips

- Use Linux every day, as your main OS or in a VM.
- Build things: automate tasks, set up a server, write scripts.
- Join [Linux.org](https://www.linux.org), [r/linux](https://www.reddit.com/r/linux/) and [LinuxQuestions.org](https://www.linuxquestions.org).
- Next: Docker, Kubernetes, DevOps.
