# Internships

A remote software engineering internship, from beginner to hire-ready. Backend focus.

Companies hire on three signals: proof of work, fundamentals, communication.

## 1. Programming basics

This phase decides how hard everything after it will be.

- [x] Variables, loops, logic
- [x] Control flow and functions
- [x] Basic OOP: classes, objects
- [x] Debugging and readable code

Go deep in one language. Recruiters prefer depth in one over basics in three.

| Language | For | Course |
|:--|:--|:--|
| Python | Backend, AI, data | [Complete Python Developer: Zero to Mastery](https://www.udemy.com/course/complete-python-developer-zero-to-mastery/) (Andrei Neagoie) |
| JavaScript | Full-stack | [The Complete JavaScript Course](https://www.udemy.com/course/the-complete-javascript-course/) (Jonas Schmedtmann) |
| Java | Enterprise, DSA | [Java Programming Masterclass](https://www.udemy.com/course/java-the-complete-java-developer-course/) (Tim Buchalka) |

## 2. CS basics

Most intern interviews filter here.

- Arrays, strings, hash maps
- Stacks, queues, linked lists
- Recursion, sorting, binary search
- Time and space complexity

**Learn:** [Mastering Data Structures & Algorithms using C and C++](https://www.udemy.com/course/datastructurescncpp/) (Abdul Bari) · [Python for Data Structures, Algorithms, and Interviews](https://www.udemy.com/course/python-for-data-structures-algorithms-and-interviews/) (Jose Portilla)

**Practice:** 100–150 LeetCode or HackerRank problems, easy to medium.

**Resume line:** "Solved 150+ DSA problems with a focus on time and space efficiency."

## 3. Git and GitHub

Remote teams can't work without it.

- [ ] Feature branches
- [ ] Pull requests and code reviews
- [ ] Merge conflicts
- [ ] Professional READMEs

**Learn:** [The Git & GitHub Bootcamp](https://www.udemy.com/course/git-and-github-bootcamp/) (Colt Steele)

## 4. Web basics

Backend interns still need to know how the web works.

- HTTP and HTTPS, status codes
- Client-server model, REST APIs
- JSON

**Learn:** [REST APIs with Flask and Python](https://www.udemy.com/course/rest-api-flask-and-python/) (Jose Salvatierra)

**Build:** A to-do REST API that keeps data in memory, no database.

## 5. Backend

Pick the stack that matches your language.

| Stack | Why | Course |
|:--|:--|:--|
| Python and FastAPI | Fast, modern, easy to learn | [FastAPI: The Complete Course](https://www.udemy.com/course/fastapi-the-complete-course/) (Eric Roby) |
| Node.js | JavaScript everywhere, huge ecosystem | [Node.js, Express, MongoDB & More](https://www.udemy.com/course/nodejs-express-mongodb-bootcamp/) (Jonas Schmedtmann) |
| Java and Spring Boot | Enterprise, large systems | [Spring Boot 3, Spring 6 & Hibernate](https://www.udemy.com/course/spring-hibernate-tutorial/) (Chad Darby) |

## 6. Databases

Data is the heart of the backend.

- SELECT, INSERT, UPDATE, DELETE
- Schema design, normalization, relationships
- Indexes and transactions

**Learn:** [SQL and PostgreSQL: The Complete Developer's Guide](https://www.udemy.com/course/sql-and-postgresql/) (Stephen Grider)

## 7. Auth, security, testing

This separates hobbyists from professional interns.

- Authentication vs authorization, JWT vs sessions, password hashing
- Build a login system with protected routes
- Unit tests and API tests

**Learn:** [Testing in Python with Pytest](https://www.udemy.com/course/testing-in-python-with-pytest/)

**Resume line:** "Implemented secure JWT authentication with 80% test coverage."

## 8. Deployment

Remote teams expect you to know containers.

- Docker and Docker Compose
- Handle `.env` secrets safely
- Deploy to Render, Railway or AWS EC2

**Learn:** [Docker and Kubernetes: The Complete Guide](https://www.udemy.com/course/docker-and-kubernetes-the-complete-guide/) (Stephen Grider)

## 9. Projects

The most important step. Build 3–4 strong projects. No calculators, no basic to-do lists.

1. **Task management API:** auth, database, CRUD, Docker
2. **Job board backend:** filters, pagination, user roles
3. **Expense tracker:** chart data endpoints, reports
4. **Application tracker:** Kanban-style status updates

Every project needs:
- [ ] A README with setup steps and screenshots
- [ ] API docs: Swagger, OpenAPI or a Postman collection
- [ ] `docker-compose up` runs the whole stack
- [ ] Unit tests on critical paths

## 10. Apply

Boards, GitHub lists and tips are in [Jobs](Jobs.md).

## Ready when

- [ ] One strong language
- [ ] Easy and medium DSA problems feel comfortable
- [ ] Active GitHub with 3+ pinned projects
- [ ] Backend skills: APIs, database, auth, Docker
- [ ] A resume that shows impact, not duties

Remote internships are competitive. Proof of work beats certificates. Build, commit, ship.
