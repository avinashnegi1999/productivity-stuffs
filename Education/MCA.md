# MCA

The NIT MCA syllabus against your Udemy courses. Where you're ready, and where you're not. 2025–2027.

| Status | Meaning |
|:--|:--|
| Covered | You're ready. Review notes and projects. |
| Gap | Heavy theory at NIT. Take a focused course. |
| Critical | NIT requires it. Bootcamps don't teach it. Act now. |
| Skip | Non-technical subject. |

## Semester 1: Foundations

Python, math, digital logic, operating systems, data structures.

| Code | Course | Credits | Status | Note |
|:--|:--|--:|:--|:--|
| CA711 | Problem solving and programming (Python) | 3 | Covered | 100 Days of Code covers it fully |
| CA713 | Mathematical foundations | 4 | Critical | Sets, graph theory, automata aren't in coding courses |
| CA715 | Digital logic and computer organization | 3 | Gap | Gates, circuits, memory architecture |
| CA717 | Data structures and applications | 3 | Gap | NIT uses C. Most courses use Python or JavaScript. |
| CA719 | Operating systems | 4 | Gap | Scheduling, deadlocks, kernel design |
| CA701 | Problem solving lab (Python) | 2 | Covered | |
| CA703 | Data structures lab (C) | 2 | Critical | Build linked lists and trees in C |

**Fill the gaps**
- [Master Discrete Math: Logic, Sets, Graph Theory](https://www.udemy.com/course/master-discrete-mathematics/) for CA713
- [Computer Organization & Architecture](https://www.udemy.com/course/computer-organization-and-architecture-explained/) for CA715: gates, memory, CPU design
- [Data Structures & Algorithms in C](https://www.udemy.com/course/mastering-data-structures-and-algorithms-in-c-and-cpp/) for CA717 and CA703. Don't use Python here.

## Semester 2: Core engineering

Algorithms, Java, databases, networks.

| Code | Course | Credits | Status | Note |
|:--|:--|--:|:--|:--|
| CA710 | Design and analysis of algorithms | 4 | Covered | Master the Coding Interview helps. Add formal Big O proofs. |
| CA712 | Database management systems | 3 | Covered | SQL Bootcamp is enough |
| CA714 | Probability and statistical methods | 4 | Critical | Hypothesis testing and ANOVA aren't in dev courses |
| CA716 | Object-oriented programming | 4 | Critical | NIT uses Java. Take a dedicated Java course. |
| CA718 | Computer networks | 3 | Gap | OSI model, TCP/IP in depth, subnetting |
| CA704 | Computer networks lab | 2 | Gap | Packet tracing, router configuration |

**Fill the gaps**
- [Java Programming Masterclass](https://www.udemy.com/course/java-the-complete-java-developer-course/) for CA716: OOP, multithreading, Swing
- [Probability & Statistics for Data Science](https://www.udemy.com/course/probability-and-statistics-for-business-and-data-science/) for CA714: distributions, hypothesis testing
- [The Complete Networking Fundamentals](https://www.udemy.com/course/complete-networking-fundamentals-course/) for CA718: OSI, TCP/IP, routing

## Plan

1. **Before semester 1, summer 2027:** Buy C programming and Discrete Math. These two fail most students.
2. **During semester 1:** Focus on data structures in C.
3. **Winter break 2027:** Start the Java Masterclass for semester 2 OOP.
4. **Semesters 4–5:** Don't rely on NIT for web and mobile. Build real portfolio projects, not just lab files.
