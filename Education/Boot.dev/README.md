## Notes

**Only one month of Premium?** Finish phases 1–4. That's about 10–12 strong certificates.

**Skip early on:** Kubernetes, overkill for juniors · extra HTTP clients in JS or TS, duplicates · Go projects before Python is solid · the capstone before you have experience.
